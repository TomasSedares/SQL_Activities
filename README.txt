## How to run the scripts

Each `.sql` file includes the creation of the database, tables, sample data, and the queries for the practical assignment.

**From the terminal:**
```bash
mysql -u your_username -p < filename.sql
```

**From MySQL Workbench:**
1. `File → Open SQL Script...`
2. Select the `.sql` file
3. Run the entire script (⚡ or `Ctrl+Shift+Enter`)

Requires MySQL 8.0 or higher.
